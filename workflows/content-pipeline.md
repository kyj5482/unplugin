# Workflow: 콘텐츠 파이프라인 (마케팅)

트리거: CS의 피드백 중 `offline_story`가 생생한 건, 또는 대표의 콘텐츠 지시.

```
[cs] offline_story 발견 → 마케팅에 소재 브리핑 (Flow에 핸드오프 기록)
   │
   ▼
[marketing] 3막 구조 초안 작성 → drafts/ 저장
   │          (위임 전 일상 → 위임 → 되찾은 오프라인 장면)
   ▼
대표 승인 (게시는 반드시 승인 후)
   │
   ▼
[marketing] 채널 게시 → published/로 이동, 채널·URL 기록
   │
   ▼
[concierge] Flow 완결, 반응이 오면 cs가 수집해 다음 소재로 순환
```

## 규칙
- 고객 실명·식별 정보는 익명화한다.
- 스토리에 Reclaimed Hours 숫자를 반드시 포함한다.
