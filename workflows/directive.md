# Workflow: 대표 지시 처리

트리거: 대표가 "지시: ..." 입력 (신규 상품기획, 개선, 개발, 콘텐츠 등).

```
대표 지시
   │
   ▼
[concierge] 접수 — flows/에 Flow 문서 생성, 담당 부문 결정
   │        (복수 부문 관여 시 주관 부문 1곳 + 핸드오프 순서 정의)
   ▼
[담당 부문] 자기 CLAUDE.md 규칙에 따라 처리
   │        산출물은 자기 부문 디렉토리에 저장
   ▼
[concierge] 결과 검증 — "Reclaimed Hours를 늘리는가?" 관점으로 1회 검토
   │
   ▼
대표에게 결과 반환: 산출물 경로 + Flow 경로 + 다음 단계 제안 1개
```

## 규칙
- 담당 부문이 모호하면: 고객 경험/추천/요금 → product, 글/채널 → marketing, 코드/도구/홈페이지 → it, 고객 대화/피드백 → cs.
- 결과 반환 시 반드시 "맥북에서 확인하는 방법"을 한 줄 포함한다 (파일 열기, 스크립트 실행 등).
