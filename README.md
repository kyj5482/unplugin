# Unplugin

> 디지털에 쓰는 시간을 AI 에이전트에게 위임하고, 그 시간을 오프라인의 진짜 경험으로 되돌려주는 컨시어지 서비스.

## 무엇이 다른가

Meta Muze, OpenAI Dots 같은 AI 비서는 "일을 대신 해주는 것" 자체가 목적입니다.
Unplugin의 목적은 그 다음입니다 — **확보된 시간을 오프라인에서 더 가치 있게 쓰도록 발굴하고 개인화 추천하는 것.**

- 병원 문진처럼, 사용자가 지금 디지털로 무엇을 하고 있는지 Survey
- 그중 하나씩 골라 AI 에이전트에게 위임
- 확보된 시간만큼 오감을 자극하는 오프라인 경험을 추천

## 북극성 KPI

**온라인 시간 → 오프라인 시간 전환량 (Reclaimed Hours)**

모든 부문의 의사결정은 이 지표를 높이는 방향으로 정렬됩니다. 상세 설계는 [`ops/kpi.md`](ops/kpi.md).

## 회사 구조 (1인 대표 + AI 에이전트 부문)

이 저장소는 실제로 운영되는 회사입니다. 대표(사람) 1명이 지시하고, AI 에이전트 부문들이 유기적 워크플로우로 업무를 처리합니다.

```
unplugin/
├── CLAUDE.md              # 회사 헌장 (미션·KPI·운영 원칙만. 실무 규칙은 각 부문에)
├── .claude/agents/        # 실행 가능한 부문 에이전트 (Claude Code 서브에이전트)
├── departments/           # 부문별 CLAUDE.md — 각 부문이 독립적으로 바이브코딩/진화
│   ├── product/           #   상품기획: 오프라인 경험 발굴·개인화 추천·문진 설계
│   ├── marketing/         #   마케팅: 사용자 스토리 기반 콘텐츠
│   ├── it/                #   IT: 에이전트·툴·서비스 개발 (AI 브라우저 세션 연동 포함)
│   └── cs/                #   CS: 고객 응대·문진 진행·피드백 수집
├── workflows/             # 부문 간 업무 흐름 정의 (고객 요청, 대표 지시, 콘텐츠 파이프라인)
├── flows/                 # 실행된 모든 업무 Flow의 기록 — 대표가 한눈에 보는 Unified View
├── ops/                   # KPI 설계, 큐 기반 요금제, 온보딩 문진
└── docs/                  # 회사 홈페이지 (GitHub Pages)
```

## 시작하기 (대표용)

맥북에서 Claude Code로 이 저장소를 열고:

1. **고객 요청 처리**: "고객 요청: ○○○" 라고 입력하면 컨시어지 에이전트가 부문에 배분하고 `flows/`에 전 과정을 기록합니다.
2. **신규 기획/개선 지시**: "지시: ○○○" 라고 입력하면 해당 부문 에이전트가 처리하고 결과를 반환합니다.
3. **Flow 확인**: `flows/` 디렉토리에서 모든 업무 흐름을 시간순으로 확인합니다.
