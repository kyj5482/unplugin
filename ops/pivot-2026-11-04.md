# 피벗 선언 — "대행 컨시어지"에서 "시간 배당 코치"로 (2026-11-04, 대표 지시)

## 배경

대표가 Meta Muze를 직접 사용해본 결과, 개인 비서형 업무 대행은 Muze 수준의
범용 에이전트가 이미 대부분 수행한다. 이 영역은 빅테크의 기술 발전 속도가
우리의 1인 회사 실행 역량을 항상 앞선다. **우리가 대행 실행 계층을 직접
만드는 경쟁은 접는다.**

대신, 범용 에이전트가 해결하지 **않는** 문제에 선다:
사람들이 AI로 시간을 벌고도 그 시간을 어디에 쓰는지 아무도 챙기지 않는다.
나태해지거나, "모든 걸 AI가 해준다"는 두려움에 머물거나.

## 새 포지션 (한 문장)

**Unplugin은 일을 대신하지 않는다. AI 에이전트(Muze 등)가 벌어준 시간을
자동으로 측정하고, 그 시간을 사람과의 관계·배움·오감 경험이라는
다음 무브먼트로 전환시키는 코치다.**

## 제품 3축

### 축 1 — 자동 측정 (Auto-Measured Dividend)

**절대 원칙: 사용자에게 수동 기록을 요구하지 않는다.** 측정이 수동이면 제품이 죽는다.

- 신호 소스:
  1. **에이전트 완료 알림 메일 파싱** — Muze 등 에이전트의 "작업 완료" 알림 메일을
     전용 주소로 자동 포워딩(1회 설정)받아 파싱. 기존 이메일 채널 자산
     (`ops/email-channel.md`, `core/mail_io.py`, `core/classify.py`)을 그대로 전용한다.
  2. **업무 유형별 기준치 테이블** — `core/plugins/` 카탈로그 103종에 유형별
     `baseline_minutes`(사람이 직접 할 때 소요)와 `emotion_load`(감정 부하 1~5)를
     부여. 완료 신호가 오면 유형 매칭 → 자동 적립. 스트레스 플레이북 10유형
     (`core/stress.py`)은 감정 부하 최고 등급 — 환불·분쟁은 시간보다 감정 절약이 크다.
  3. **스크린타임 델타** — 자가보고 아닌 행동 지표로 교차 검증 (기존 TC-OFF-004 유지).
- Task마다 표시: **절약 시간** + **아끼지 않은 감정**(감정 부하 × 회피 횟수).
  누적치는 "시간 배당 잔고"로 보여준다.

### 축 2 — 위임 팁 엔진 (Delegation Tips)

이메일을 연결해 **대신 처리하는 게 아니라**, "이 일은 Muze에 이렇게 요청하면
약 N시간 절약" 팁 카드를 준다.

- `core/classify.py`의 트리거 매칭을 역방향으로 쓴다: 수신 업무를 분류 →
  해당 유형의 에이전트용 프롬프트 템플릿 + 예상 절약치 + 감정 부하를 카드로 제시.
- 103종 플러그인 카탈로그 = 팁 지식베이스. 스트레스 플레이북 10종 =
  "입금 확인까지 끝까지 시키는 법" 고급 팁.
- 사용자가 Muze에서 실행하면 → 축 1의 완료 알림 수신으로 **자동 확인** →
  잔고 적립. 팁 → 실행 → 적립의 루프가 닫힌다.

### 축 3 — 넥스트 무브먼트 (Next Movement)

적립된 시간이 잔고에 쌓이기만 하면 의미가 없다. 임계치마다 전환을 제안한다:

- **관계** — 사람들과의 네트워크(만날 사람, 모임)
- **배움** — 좋아하고 배워보고 싶은 것(클래스, 공방)
- **오감** — 감각을 온전히 즐기는 경험(기존 상품기획 카탈로그 전용)

전환이 실제 일어났는지는 기존 깔때기(Reclaimed Hours)로 측정. 메시지의 핵심:
AI는 나를 나태하게 만드는 것도, 두려워할 것도 아니다 —
**사람으로서 성장할 시간을 벌어주는 것**이다.

## KPI 깔때기 개정

```
① Saved Hours      : 에이전트가 벌어준 시간 — 자동 측정 (수동 입력 금지)
   + Emotion Saved : 회피한 감정 부하 (업무 유형별 가중)
        ▼ × 전환율
② Reclaimed Hours  : 그 시간 중 실제 오프라인 무브먼트로 쓰인 시간 (북극성 유지)
        ▼ × 깊이
③ Growth           : 관계·배움·오감의 깊이 (구 Experience Depth 확장)
```

상세: `ops/kpi.md`
