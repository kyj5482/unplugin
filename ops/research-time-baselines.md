# 시간 기준치·감정 부하 근거 조사 (2026-11-04, 상품기획 리서치)

시간 배당의 `baseline_minutes`(유형별 1건당 사람이 직접 할 때 소요 분)와
`emotion_load`(감정 부하 1~5)에 **출처를 달기 위한** 웹 조사 결과.
조사 방법: 공식 통계·논문·규제기관 발표를 WebFetch로 직접 확인(아래 A급),
복수 언론 교차 보도로 확인(B급), 확인 불가 항목은 내부 추정으로 정직 표기(C급).

## 산정 원칙

```
적립 시간 = baseline_minutes(유형) × time_factor(개인)
```

1. **문헌 기준치**: 범위(low~high)와 권장값을 아래 표로 정의. 출처 수치의
   단위 변환(예: 하루 참여자 평균 → 1건당)은 "변환" 열에 명시 — 변환 가정이
   들어간 값은 출처가 A여도 **값 등급은 한 단계 낮춰** 표기한다.
2. **개인 보정 계수(time_factor)**: 같은 과제도 사람마다 소요가 크게 다르다
   (아래 §개인차). 기본 1.0, 범위 0.6~1.6. 사용자 수동 입력 없이 Admin이
   조정하거나 추후 행동 신호(스크린타임 델타, 보고 메일 왕복 수)로 보정.
3. **감정 부하**: 회피·분쟁·관료 절차 유형일수록 높게 — 심리 비용(A급 문헌)
   근거. 숫자(1~5)는 서수적 내부 척도이며 절대량 측정이 아님을 UI에 명시.

## 증거 등급

- **A** — 공식 통계·학술 문헌·규제기관 발표를 원문으로 직접 확인
- **B** — 산업 리포트·설문, 또는 공식 발표의 복수 언론 교차 보도
- **C** — 출처 미확보, 내부 추정 (정직하게 표기하고 추후 보강)

## 개인차 — time_factor 설계

- **근거**: 같은 "구매" 활동도 ATUS에서 전체 평균 0.69h vs 참여자 평균 1.74h,
  성별 차(여 1.80h/남 1.67h)가 확인된다(S1) — 수행 여부·소요가 사람마다 크게
  갈린다. 가사·돌봄도 한국 조사에서 2배 이상 성별 격차(S6). 회피 성향이 높은
  사람은 동일 과제의 정서 비용·지연이 더 크다(S5).
- **설계**: `profile.time_factor` 기본 1.0, 권장 범위 **0.6~1.6**.
  - v0: Admin이 온보딩 정보(가구 형태·위임 전 자가 추정)로 설정, 이후 조정.
  - v1: 스크린타임 델타·보고 메일 왕복 횟수 등 행동 신호로 자동 보정.
  - **사용자 수동 기록은 어떤 단계에도 없다** (안티지표 준수).
- 감정 부하는 개인 보정 없이 유형 고정으로 시작 — 과장 방지, 서수 척도 유지.
