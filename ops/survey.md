# 온보딩 문진 v0 — "디지털 시간 문진표"

병원 문진처럼, 고객이 지금 디지털로 무엇을 하고 있는지 파악하고 **한 가지씩** 위임을 시작한다.
소유: 상품기획 / 진행: CS

## 문진 (약 5분)

**Q1. 하루 중 화면을 보는 시간은 대략 몇 시간인가요?** (스크린타임 앱 수치가 있으면 그대로)

**Q2. 다음 중 매주 반복적으로 시간을 쓰는 디지털 일이 있다면 모두 골라주세요.**
- 장보기·생필품 주문 / 가격 비교·최저가 검색
- 예약 (병원, 식당, 미용실, 여행)
- 메일·메시지 정리, 각종 신청·서류 처리
- 콘텐츠 탐색 (뭘 볼지·살지·갈지 고르느라 스크롤)
- 금융·공과금·구독 관리
- 기타: ___

**Q3. 그중 "내가 직접 안 해도 되는데"라고 느끼는 일 하나는 무엇인가요?** → 첫 위임 후보

**Q4. 반대로, 직접 하는 게 즐거워서 뺏기고 싶지 않은 디지털 활동은?** → 위임 금지 목록

**Q5. 시간이 생기면 해보고 싶었던 오프라인 활동이 있나요?** (없어도 괜찮습니다 — 찾아드리는 게 저희 일입니다)

**Q6. 오감 중 요즘 가장 메말랐다고 느끼는 감각은?** (보기: 손으로 만드는 촉감 / 계절 냄새 / 직접 끓인 맛 / 라이브의 소리 / 화면 밖 풍경) → 경험 추천의 축

**Q7. 당신의 여유 시간 1시간은 얼마의 값어치가 있다고 생각하세요?** → 요금제 검증용 (ops/pricing.md)

## 문진 후 처리

1. CS가 결과를 `departments/cs/feedback/`에 고객 프로필로 기록
2. Q3 항목 하나만 첫 위임으로 설정 (일괄 위임 만류)
3. Q5·Q6를 상품기획에 전달 → 첫 오프라인 추천 생성
4. 2주 후 재문진: Q1 변화 + Reclaimed Hours 실측
